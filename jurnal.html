Bagian Ketiga (TP4): Perburuan Kesalahan

1. Analisis Kode Rusak 1

Kode Asli pada Foto:

<head>
<script>
function Sapa() {
    alert("Selamat datang");
}
</script>
</head>
<body onload="sapa();">
  • Temuan Kesalahan: Ada perbedaan huruf pada nama fungsi. Fungsi yang dibuat bernama Sapa() (pakai 'S' besar), sedangkan yang dipanggil di dalam tag body adalah sapa() (pakai 's' kecil).
  • Perbaikan dan Hasil: Samakan hurufnya. Kita bisa mengubah pemanggilnya atau fungsi aslinya agar sama-sama menggunakan huruf kecil. 
    <head>
<script>
function sapa() {
    alert("Selamat datang");
}
</script>
</head>
<body onload="sapa();">
    Hasil Eksekusi: Saat halaman web dimuat ulang, layar akan langsung memunculkan pop-up alert bertuliskan "Selamat datang".
  • Penjelasan Penyebab: JavaScript bersifat case-sensitive, artinya huruf besar dan huruf kecil dianggap berbeda. Kalau fungsinya dibuat dengan huruf kapital Sapa() tetapi dipanggil dengan huruf kecil sapa(), browser kebingungan karena merasa fungsi sapa() belum pernah didefinisikan.

2. Analisis Kode Rusak 2

Kode Asli pada Foto:

function hitung() {
    var x = prompt("Angka pertama");
    var y = prompt("Angka kedua");
    alert("Jumlahnya " + x + y);
}
/* Pengguna mengetik 5 dan 3, tetapi yang muncul bukan 8. */
  • Temuan Kesalahan: Hasil input dari prompt() otomatis dibaca sebagai teks atau string, bukan angka numerik. Saat digabungkan dengan simbol +, sistem merangkai teksnya, bukan menambahkannya.
  • Perbaikan dan Hasil: Ubah tipe datanya dari teks menjadi angka dengan Number(). 
    function hitung() {
    var x = Number(prompt("Angka pertama"));
    var y = Number(prompt("Angka kedua"));
    var hasil = x + y;
    alert("Jumlahnya " + hasil);
}
    Hasil Eksekusi: Saat pengguna memasukkan angka 5 lalu 3, alert yang muncul sekarang menampilkan "Jumlahnya 8".
  • Penjelasan Penyebab: Fungsi prompt() selalu menangkap input sebagai teks. Dalam JavaScript, kalau teks dihubungkan dengan tanda +, sistem menempelkan kedua karakter (string concatenation), sehingga teks "5" ditambah teks "3" menjadi "53". Agar bisa dihitung sebagai angka, konversi dengan Number().

3. Analisis Kode Rusak 3

Kode Asli pada Foto:

function cek(nilai) {
    if (nilai = 100) {
        alert("Nilai sempurna");
    } else {
        alert("Belum sempurna");
    }
}
/* cek(20) tetap mengatakan sempurna. */
  • Temuan Kesalahan: Menggunakan tanda sama dengan tunggal (=) di dalam tanda kurung kondisi if. Simbol = fungsinya untuk menetapkan nilai, bukan membandingkan.
  • Perbaikan dan Hasil: Ganti tanda sama dengan tunggal menjadi operator perbandingan kesetaraan, yaitu dua (==) atau tiga (===) tanda sama dengan. 
    function cek(nilai) {
    if (nilai === 100) {
        alert("Nilai sempurna");
    } else {
        alert("Belum sempurna");
    }
}
    Hasil Eksekusi: Saat fungsi dipanggil dengan cek(20), alert yang muncul adalah "Belum sempurna".
  • Penjelasan Penyebab: Tanda = tunggal adalah assignment operator. Saat kode menjalankan if (nilai = 100), sistem tidak mengecek, melainkan mengubah isi variabel nilai menjadi 100 saat itu juga. Karena 100 dianggap truthy, program selalu menjalankan blok "Nilai sempurna" berapapun angka masukannya.

Refleksi Pertemuan 5

  1. Apa yang terjadi bila satu break pada namaHari dihapus?
    Program akan mengalami fall-through: case yang cocok dijalankan, lalu diteruskan ke case berikutnya tanpa berhenti karena tidak ada break. Akibatnya hasil bisa tertimpa nilai case berikutnya, sehingga fungsi mengembalikan nama hari yang salah. Contoh nyata: kalau break pada case 3 dihapus, memanggil namaHari(3) akan mengembalikan "Kamis" karena eksekusi jatuh ke case berikutnya.
  2. Baris Tabel Telusur Perulangan yang ramalannya meleset dan penyebabnya.
    Untuk NIM 2510514025 semua ramalan cocok. Bila ada yang meleset, penyebab paling umum adalah keliru menghitung berapa kali do...while berputar (karena syarat diperiksa di akhir) atau menganggap n++ di dalam nested loop hanya berputar sekali, padahal dikalikan jumlah loop luar.
  3. Perbedaan while dan do...while berdasarkan percobaan.
    Pada baris 2 (while (j < b)) kalau nilai b = 0, badan perulangan tidak akan dijalankan sama sekali. Tetapi pada baris 3 (do...while), badan perulangan tetap dijalankan minimal satu kali walaupun k > 0 sudah salah di awal. Jadi while memeriksa syarat dulu, do...while menjalankan dulu baru memeriksa.
  4. Pernah mengalami perulangan tak berhenti?
    Pernah. Penyebabnya waktu itu lupa menambah nilai variabel pencacah sehingga syarat selamanya benar. Saya sadar karena tab browser membeku dan muncul peringatan "Halaman tidak merespons". Cara keluarnya: menutup tab paksa lewat Task Manager, lalu memperbaiki kode dengan memastikan variabel pencacah bertambah di dalam badan perulangan dan menambahkan pembatas percobaan maksimum.
  5. Mengapa infoLengkap bisa memanggil method induk padahal tidak ditulis di Praktikan?
    Karena class Praktikan extends Mahasiswa. Dengan inheritance, seluruh method milik Mahasiswa (termasuk infoDasar() dan hitungSemester()) otomatis diwariskan ke Praktikan melalui prototype chain. Jadi this.infoDasar() di dalam infoLengkap() tetap bisa dipanggil, karena this mengacu ke objek Praktikan yang juga punya rantai ke Mahasiswa.

Percobaan Console: Class dan Inheritance (TP5 F.f)

Tiga percobaan sengaja dilakukan untuk melihat pesan error di Console, lalu kode dikembalikan seperti semula.

Percobaan 1: Hapus new saat Membuat Objek

Kode yang dijalankan:

var m1 = Mahasiswa("Muhammad Farand Danendra", "2510514025", 2025);

Output di Console:

TypeError: Class constructor Mahasiswa cannot be invoked without 'new'

Mengapa gagal: Constructor class wajib dipanggil dengan new. Tanpa new, JavaScript menolak karena class bukan fungsi biasa. Kalau ingin memanggil seperti fungsi, gunakan fungsi biasa (function Mahasiswa(...) {}) atau constructor function, bukan sintaks class.

Percobaan 2: Hapus super() di Constructor Praktikan

Kode yang dijalankan:

class PraktikanRusak extends Mahasiswa {
    constructor(nama, nim, tahunMasuk, kelasPraktikum) {
        // super(nama, nim, tahunMasuk);   <-- dihapus sementara
        this.kelasPraktikum = kelasPraktikum;
    }
}
var p2 = new PraktikanRusak("Muhammad Farand Danendra", "2510514025", 2025, "A - Sains Data");

Output di Console:

ReferenceError: Must call super constructor in derived class before accessing 'this' or returning from derived constructor

Mengapa gagal: Class turunan (extends) tidak boleh memakai this sebelum super() dipanggil. super() bertugas memanggil constructor induk (Mahasiswa) agar properti nama, nim, dan tahunMasuk terpasang dulu.

Percobaan 3: Panggil infoLengkap pada Objek Mahasiswa

Kode yang dijalankan:

var m3 = new Mahasiswa("Muhammad Farand Danendra", "2510514025", 2025);
m3.infoLengkap(2026);

Output di Console:

TypeError: m3.infoLengkap is not a function

Mengapa gagal: Method infoLengkap hanya ada di class Praktikan. Inheritance mengalir dari induk ke anak, bukan sebaliknya. Objek Mahasiswa adalah induk, jadi tidak mewarisi method yang hanya ada di anak.
